# ГОРИЗОНТ — сайт веб-студии на WordPress

Авторская блочная тема, независимый плагин управления содержимым и демонстрационное наполнение. Сайт на русском языке. Светлая концепция опирается на обсуждение по предоставленной ссылке: тёплый фон, единая типографика Inter, выразительные заголовки, согласованные компоненты и адаптивная композиция.

Исходники: https://github.com/mebsms21/Gorizont-web . Проверки запускаются автоматически через GitHub Actions. Репозиторий содержит тему, плагин и установщик; база, локальные пароли и пользовательская медиатека в Git не включаются.

## Быстрый запуск

Нужны Docker Engine / Docker Desktop с Compose v2, Bash и OpenSSL. Рекомендуется 8 ГБ свободного диска; Docker с драйвером VFS может расходовать существенно больше. На Windows запускайте команды в WSL2.

```bash
./bin/setup.sh
```

Сайт: **http://localhost:8080**. Панель: **http://localhost:8080/wp-admin/**. Имя и уникальный пароль администратора находятся в локальном `.env`. Секреты генерируются автоматически; в архив они не входят.

Локальная среда: WordPress 7.1.4, PHP 8.3, MariaDB 11.4, PHP dev server. Сервер слушает только localhost. Он предназначен для разработки. Для проверки связки Nginx + PHP-FPM предусмотрен отдельный файл `compose.nginx.yaml`; в текущей ограниченной среде он не запускался полностью. Для хостинга используйте стандартный WordPress на PHP-FPM/Apache/Nginx по инструкции ниже.

Первый запуск требует интернет для WordPress и русской локализации. Изображения, шрифт и демоматериалы входят в проект и импортируются без обращения к внешним сервисам. Повторный `setup.sh` сохраняет установленный WordPress; повторный импорт запускается отдельно.

## Состав

- `wp-content/themes/gorizont/` — собственная блочная тема Gutenberg, шаблоны, паттерны, стили и локальный Inter.
- `wp-content/plugins/gorizont-core/` — услуги, проекты, категории, характеристики, контакты, SEO, динамические блоки и демоимпорт.
- `docker/`, `compose.yaml`, `bin/` — воспроизводимая локальная среда.
- `tests/` — интеграционные проверки WordPress и браузерные проверки.
- `docs/` — архитектура, работа редактора, развёртывание, источники и отчёт.

Шесть демостраниц, четыре услуги, три вымышленные концепции портфолио и отдельное меню. Демоимпорт не создаёт фиктивных отзывов, наград или показателей.

## Команды

```bash
docker compose up -d --wait       # запуск после установки
./bin/wp gorizont demo            # добавить недостающие демоматериалы
./bin/wp eval-file /tests/integration.php
npm ci
npx playwright install chromium
npm run test:browser
docker compose stop              # остановить, сохранив данные
```

`docker compose down` сохраняет именованные тома. `docker compose down -v` удаляет базу и медиатеку — применяйте только при намеренном сбросе локальной копии.

Приложение не требует Node.js для работы: Node используется только в проверках. Elementor, коммерческие темы, ACF и внешние визуальные конструкторы отсутствуют.
