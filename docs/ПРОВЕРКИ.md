# Проверка обновлённого дизайна 3.1

Проверено 12 ноября 2026 года на реальном локальном WordPress с MariaDB, Gutenberg и медиатекой. Chromium / Playwright, axe-core и Lighthouse. Публичная версия собирается из этого WordPress в статические HTML.

## Результаты

- PHP lint темы и плагина: ошибок синтаксиса нет; JavaScript синтаксически корректен.
- 13 интеграционных проверок: блочная тема, Gutenberg / REST, повторный импорт без дубликатов и потери правок, права записи, очистка метаполей и контактов, nonce, фильтр и пустые результаты.
- Восемь страниц WordPress: HTTP 200, русский язык, один H1, без ошибок JavaScript и запросов отсутствующих ресурсов.
- Ширины 360 / 390 / 768 / 1024 / 1440 / 1920: без горизонтальной прокрутки.
- Меню: открытие, закрытие Escape; фильтр портфолио; русская 404; скачивание брифа; учёт reduced motion.
- Админка: вход, настройки, сохранение отрывка услуги через Gutenberg с последующим восстановлением. Главная и услуга без невалидных блоков.
- axe-core WCAG 2 A/AA и 2.1 AA: ноль автоматических нарушений на восьми страницах. Проверка устойчивого состояния с reduced motion, чтобы анимация появления не искажала измерение контраста.
- Статический экспорт: 22 страницы, шесть ширин, меню и скачивание брифа работают; отсутствующих ресурсов и ошибок JavaScript в проверке нет.
- Скриншоты десктопа и телефона визуально сверены с восстановленными макетами. Допустимые отличия описаны в [ДИЗАЙН.md](ДИЗАЙН.md).

## Lighthouse

Последний мобильный замер localhost: производительность **95**, доступность **100**, Best Practices **100**. LCP 2,3 с, CLS 0, TBT 160 мс. Предыдущий замер производительности 97. Показатели зависят от среды и не гарантируют такие же значения на хостинге. SEO в этом замере не оценивалось: демоверсия намеренно закрыта от индексации.

## Ограничения

GitHub Pages обслуживает статическую демоверсию. WordPress и его админка работают в подготовленной локальной среде, для публичной админки нужен PHP/MySQL-хостинг. Обращения, CRM и настоящая почта не подключены; форма честно скачивает бриф без отправки. Концепции портфолио, реквизиты и юридические тексты требуют замены перед коммерческим запуском. Автоматическая доступность не заменяет ручную проверку с ассистивными технологиями.
