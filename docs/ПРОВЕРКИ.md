# Результаты проверки «ГОРИЗОНТ»

Проверено 12 ноября 2026 года. Рабочая среда: WordPress 7.1.4, PHP 8.3.36, MariaDB 11.4, Chromium, Playwright, axe-core, Lighthouse 13.6.0. Проверялся работающий WordPress с реальной базой данных, авторизацией, Gutenberg и медиатекой.

## Что выполнено

- Авторская блочная тема с `theme.json` v3, собственной композицией и локальным Inter.
- Независимый плагин услуг, портфолио, категорий, характеристик и контактов.
- Шесть страниц, четыре услуги, три демонстрационных проекта, навигация и медиатека.
- Редактирование страниц, текстов, изображений, шапки, подвала, меню, SEO и контактных данных в панели.
- Docker-среда для локальной работы, отдельные установочные ZIP, руководство редактора и инструкция по хостингу.

## Проверки кода и WordPress

PHP lint пройден для всех PHP-файлов темы, плагина, локального установщика, маршрутизатора и интеграционных проверок. JavaScript прошёл синтаксическую проверку Node.js, shell-скрипты — `bash -n`, оба файла Compose — `docker compose config --quiet`.

13 интеграционных проверок пройдены:

1. Активная тема поддерживает блочный редактор сайта.
2. Проекты поддерживают Gutenberg и REST.
3. Услуги поддерживают Gutenberg и REST.
4. Повторный импорт не создаёт дубликатов.
5. Повторный импорт сохраняет тексты страниц.
6. Повторный импорт сохраняет контакты.
7. Анонимный пользователь не может изменять проекты через REST.
8. Анонимный пользователь не может изменять настройки.
9. Метаполя сохраняются авторизованным пользователем, HTML очищается.
10. Контакты очищаются от опасных URL, HTML и некорректной почты.
11. Метаполя не меняются без nonce.
12. Фильтр выбирает нужную категорию.
13. Для пустого результата есть понятное сообщение.

Дополнительно выполнена чистая установка в отдельную проверочную базу: первичный PHP-установщик, включение темы/плагина и демоимпорт завершились успешно. Проверено сохранение проектов и контактов после смены темы. Проверочная база затем удалена. Повторный запуск `setup.sh` на существующей установке сохранил содержимое и настройки.

## Браузер

Восемь маршрутов: главная, услуги, проекты, студия, контакты, политика, отдельный проект и отдельная услуга. Все вернули HTTP 200, имеют русский `lang` и один H1. Проверена отдельная русская страница 404.

Ширины 360, 390, 768, 1024, 1440 и 1920 px: горизонтальной прокрутки нет. Мобильное меню открывается и закрывается Escape. Фильтр «Лендинги» оставляет нужный проект. Вход администратора работает. Отрывок услуги был изменён через Gutenberg, сохранён в БД и восстановлен. На главной и странице услуги не обнаружено невалидных блоков Gutenberg. JavaScript-ошибок и неуспешных запросов ресурсов в пройденных сценариях нет.

axe-core по WCAG 2 A/AA и WCAG 2.1 AA: **0 автоматических нарушений на каждой из восьми страниц**. Это автоматическая проверка выбранных сценариев, а не сертификация полной доступности. Штатная русская локализация установлена; проверены переводы интерфейса WordPress.

## Lighthouse, мобильный профиль

| Категория | Балл |
|---|---:|
| Производительность | 95 |
| Доступность | 100 |
| Best practices | 100 |
| SEO | 100 |

LCP 2,9 с, CLS 0, Total Blocking Time 0 мс. Применялась мобильная симуляция Lighthouse на localhost. Шрифт сокращён до необходимых латинских/кириллических символов (WOFF2 около 140 КБ), добавлена предзагрузка; превью проектов WebP около 31–73 КБ.

Для проверки SEO индексация локального сайта временно включалась: `/wp-sitemap.xml` вернул HTTP 200. После замера `blog_public=0` восстановлен. Поэтому обычная повторная проверка SEO локальной среды покажет запрет индексации — это ожидаемо до публикации. HTML-отчёт Lighthouse прилагается; локальные показатели не гарантируют те же значения на хостинге.

## Границы проверки

Доступных исходников Next.js и прежних вложенных макетов не было; перенос кода и точное визуальное сравнение с изображениями не выполнялись. Дизайн следует доступному тексту согласованного обсуждения.

На хостинг сайт не публиковался. Основная локальная конфигурация с PHP dev server проверена. Полный запуск дополнительной Nginx/PHP-FPM конфигурации не завершён из-за заполнения диска Docker VFS; её синтаксис Compose проверен. PHP dev server применяется только локально.

Демонстрационные реквизиты, проекты и юридическая заготовка требуют замены перед реальной публикацией. Реальная почта, CRM и аналитика не настраивались. Карточки и основные кнопки ведут на настоящие страницы WordPress; обращения предусмотрены через опубликованные контакты.
