Рабочий сайт веб-студии «ГОРИЗОНТ» на WordPress: светлая авторская тема Gutenberg, услуги, портфолио, контакты и демонстрационное наполнение.

- `gorizont-theme.zip` — установить через «Внешний вид → Темы».
- `gorizont-core.zip` — установить через «Плагины».
- `gorizont-wordpress.zip` — полный проект с Docker-средой, проверками и инструкциями.
- `gorizont-preview.png` — первый экран светлой концепции.

Для тестового хостинга выбран InfinityFree. [Инструкция по размещению](https://github.com/mebsms21/Gorizont-web/blob/main/docs/INFINITYFREE.md). В Actions подготовлена ручная загрузка по FTPS; для первого размещения нужны созданный hosting account, WordPress и FTP Secrets. До подключения хостинга сайт на InfinityFree ещё не опубликован.

Тема, плагин, демоимпорт и редактор проверяются в GitHub Actions. Скриншоты полных страниц доступны в артефактах проверок. Локальные пароли, база данных и пользовательские загрузки в поставку не входят. Демонстрационные реквизиты, проекты и юридическую заготовку нужно заменить перед реальным запуском.
