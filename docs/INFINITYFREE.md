# GitHub → InfinityFree: бесплатный тестовый WordPress

Исходники: https://github.com/mebsms21/Gorizont-web . Для хостинга выбран InfinityFree. По официальной странице на 12 ноября 2026 года он предоставляет бесплатный PHP/MySQL-хостинг с поддоменом и SSL без срока окончания, без оплаты картой. Действуют лимиты бесплатного сервиса; сайт должен получать посещения, чтобы оставаться активным.

## Первое размещение

1. Зарегистрируйтесь на https://dash.infinityfree.com/register и подтвердите почту. Создайте бесплатный hosting account и поддомен.
2. В панели hosting account откройте Control Panel → Softaculous Apps Installer → WordPress → Install. Выберите нужный поддомен, очистите поле установки в подкаталог (чтобы WordPress работал в корне), задайте название «ГОРИЗОНТ», русский язык и собственные реквизиты администратора. Сохраните пароль в своём менеджере паролей. Выбирайте HTTPS после выпуска и установки SSL для поддомена.
3. Отправьте тему и плагин одним из способов ниже.
4. В WordPress активируйте «ГОРИЗОНТ — Содержимое» и тему «ГОРИЗОНТ».
5. В разделе «ГОРИЗОНТ» нажмите «Добавить демоматериалы».
6. В «Настройки → Чтение» выберите статическую главную «Главная». В «Постоянные ссылки» выберите «Название записи». Проверьте меню в редакторе сайта и удалите штатные демонстрационные страницы WordPress, если они не нужны.
7. Замените демореквизиты и материалы при подготовке реального сайта. На время теста оставьте запрет индексации в настройках чтения.

## Вариант A: ZIP из GitHub Release

На странице Releases скачайте `gorizont-core.zip` и `gorizont-theme.zip`. Первый установите через «Плагины → Добавить → Загрузить», второй — через «Внешний вид → Темы → Добавить → Загрузить». Полный архив проекта предназначен для разработки; не загружайте его целиком в публичную папку хостинга.

## Вариант B: отправка файлов из GitHub Actions

В репозитории откройте **Settings → Secrets and variables → Actions → New repository secret**:

| Имя секрета | Значение из InfinityFree → FTP Details |
|---|---|
| `GORIZONT_FTP_HOST` | FTP hostname из панели (для сертификата обычно `ftpupload.net`) |
| `GORIZONT_FTP_USER` | FTP username hosting account |
| `GORIZONT_FTP_PASSWORD` | FTP password hosting account |

Пароли вводите непосредственно в GitHub Secrets. Не отправляйте их в чат и не сохраняйте в коде. База данных и её реквизиты для загрузки темы не требуются.

Основной сайт использует папку `htdocs`. Для другого webroot добавьте **Variable** `GORIZONT_FTP_ROOT`, например `example.com/htdocs`. Этот путь должен указывать на папку, в которой установлен WordPress.

Далее откройте **Actions → Загрузить на InfinityFree → Run workflow → main**. Запуск ручной: обычное сохранение кода в GitHub не меняет опубликованный сайт автоматически. После успешной загрузки проверьте сайт в браузере.

Загрузчик использует explicit FTPS, порт 21, TLS 1.2+, проверяет сертификат, защищает канал данных и сверяет размер каждого файла. Файл заменяется после полной передачи во временное имя. Загружаются только `wp-content/themes/gorizont/` и `wp-content/plugins/gorizont-core/`; база, медиатека, `wp-config.php` и другие темы/плагины не затрагиваются. Удаление удалённых файлов не выполняется.

Если сервер не передаёт полную цепочку TLS, загрузка завершится ошибкой сертификата. В этом случае нужно исправить доверенную цепочку по инструкции хостинга; проверка TLS в скрипте не отключается.

## Что проверено и что ожидает подключения

Установка WordPress с нуля, демоимпорт, интеграционные и браузерные сценарии проверяются в GitHub Actions. Для FTPS проверены границы загружаемых путей, исключение секретов/медиатеки, отказ от замены файла при несовпадении размера и локальный dry-run. Реальное подключение к InfinityFree и просмотр опубликованного сайта возможны после создания аккаунта, поддомена и настройки FTP Secrets; до этого успешная публикация не заявляется.
