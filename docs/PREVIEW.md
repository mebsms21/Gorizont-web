# Публичная демоверсия GitHub Pages

Адрес после публикации: https://mebsms21.github.io/Gorizont-web/

Демоверсия экспортирована из работающего WordPress. Она показывает дизайн, страницы услуг, портфолио, категории, контакты и мобильное меню. Друзья могут открыть публичную ссылку без регистрации. Админка и база WordPress остаются в основном проекте; на GitHub Pages их нет. Контакты и проекты демонстрационные.

Папка `preview/` содержит только публичные HTML, CSS, изображения, шрифт и небольшой скрипт мобильного меню. Пароли, PHP, база данных, cookies и административные страницы в экспорт не входят.

Для обновления после редактирования WordPress запустите локальную среду и `python3 scripts/export_preview.py`, затем сохраните изменения в Git. Workflow `pages.yml` публикует только `preview/`.

Первичное включение Pages требует права администратора: Settings → Pages → Source → GitHub Actions. Это однократная настройка. Остальные изменения демоверсии публикуются автоматически при обновлении `preview/` в main.
